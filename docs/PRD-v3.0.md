- 生成方式：通过 DeepSeek API 批量生成并校验

## 二、体验打磨

### 2.1 加载性能优化
- **词汇懒加载**：大词库（5000+词）不分批加载到内存，仅加载第一批 + 已用词排除列表
- **详情数据缓存**：已加载过的词详情存 localStorage，重复查看不走重新解析
- **骨架屏优化**：词网格、详情页、复习页骨架屏过渡更平滑

### 2.2 移动端深度适配
- **底部导航栏替代顶部复杂菜单**：小屏下 Source/Settings/Reading 按钮收到底部 TabBar
- **词网格触摸优化**：词块增大 touch target（≥44px），减少误触
- **滑动导航**：详情页支持左右滑动切换卡片
- **手势返回**：支持 iOS 左滑返回

### 2.3 交互细节打磨
- **学习进度条**：顶部显示当前批次进度（如 23/100）
- **词网格「全选/取消」操作**：支持多选标记/取消标记
- **快捷键提示工具**：键盘快捷键 toast 提示（首次使用展示）
- **自动发音开关**：设置中加"进入详情页自动朗读单词"开关
- **连续答对彩蛋**：复习时连续答对 5/10/20 词有微动效反馈

### 2.4 数据可视化
- **学习热力图**：GitHub 风格，显示过去 60 天每日学习量
- **遗忘曲线**：基于 SM-2 数据，展示各词的记忆衰退曲线
- **词频统计 TOP 榜**：常错词排行、已掌握词数趋势

### 2.5 品质提升
- 修正词库中缺失的 pronunciation/example 字段
- 设置面板增加"清除所有数据"按钮
- Toast 增加堆叠支持（多个通知不叠加覆盖）
- 空状态处理：复习池为空时友好提示
- 错误状态的优雅降级（API 失败不破页面）

### 2.6 词库数据质量改进
- 每条数据的 6 字段必须完备
- chineseDef 中文释义准确
- example 例句自然常用
- pronunciation 使用标准 IPA
