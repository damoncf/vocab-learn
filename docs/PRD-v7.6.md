# VocabLearn v7.6 — 设置页面重构

> 日期：2026-05-23

---

## 现状

当前设置页面是一个扁平列表，所有设置项无分组、无视觉层级。缺少：
- 每日目标设置
- 自适应批次大小开关
- 数据概览（已学/已掌握/连续天数）
- 导出/导入入口
- 居中保存按钮

---

## 设计方案

设置页面按功能分组为 6 个卡片区域：

### 1. 🎯 Learning（学习设置）
| 设置 | 类型 | 默认值 |
|------|------|--------|
| 每日目标 | number | 50 |
| 每批词数 | number(10-500) | 100 |
| 词汇难度 | select | Intermediate |
| 自适应批次大小 | toggle | off |

### 2. 🧠 Interaction（交互设置）
| 设置 | 类型 | 默认值 |
|------|------|--------|
| 单击行为 | select(查看释义/直接标记) | 查看释义 |
| 自动朗读 | toggle | off |
| 快捷键提示 | toggle | on |

### 3. 🎨 Appearance（外观）
| 设置 | 类型 | 默认值 |
|------|------|--------|
| 主题 | select(深色/浅色/跟随系统) | 跟随系统 |

### 4. 🔌 API
| 设置 | 类型 |
|------|------|
| DeepSeek API Key | password + show/hide |

### 5. 🔄 Sync
现有同步设置不变，增加"上次同步时间"展示

### 6. 📊 Data（数据概览 + 操作）
| 内容 | 类型 |
|------|------|
| 已学词数 | 统计展示 |
| 已掌握词数 | 统计展示 |
| 连续学习天数 | 统计展示 |
| 待复习词数 | 统计展示 |
| 导出 Anki CSV | button |
| 清除所有数据 | danger button |

---

## 实现

### 修改 index.html
将当前设置面板的扁平 DOM 重新组织为 6 个分组卡片。

### 修改 app.js
- 增加每日目标设置保存/加载逻辑
- 增加自适应批次大小逻辑（根据历史标记率自动调整）
- 数据概览区域展示统计数据
- 导出 Anki 入口绑定

### 修改 storage.js
- 增加 `getDailyGoal()` / `setDailyGoal()`
- 增加 `getAdaptiveBatch()` / `setAdaptiveBatch()`

### 修改 style.css
- 设置分组卡片样式
- 数据概览行样式
