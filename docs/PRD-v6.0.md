## 一、产品定位（回答"你是谁"）

### 核心理念

**一个句子说清楚：**
> "VocabLearn 是你自己掌控的单词学习工具。你选词、你定速、你标记。不是 App 教你学，是你自己学。"

**三个不做的：**
1. 不做社区、不做排行榜、不社交
2. 不做打卡罚款、不做焦虑推送
3. 不做算法替你决定的复习计划（SM-2 只是工具，你决定什么时候复习）

**三个做到的：**
1. 打开即学，零门槛
2. 你掌控一切：词库、速度、节奏
3. 数据和进度完全属于你（本地优先 + WebDAV 同步）

## 二、首次打开体验重做（P0）

### 问题
当前首次打开：欢迎页 → 选择词库 →（加载）→ 词网格。用户不知道"接下来干嘛"。

### 解决方案：闪屏 onboarding

```
│                              │

│                              │
│          [ 开始 ]             │
└──────────────────────────────┘
```

**屏 2：核心交互教学**
```
┌──────────────────────────────┐
│                              │

│  └──────┘                    │

│  认识？不用管，自动算熟悉     │
```

**屏 3：选词库**

- CSS 实现 fade 切换
- localStorage 标记 `hasSeenOnboarding = true`，之后不再展示
- 设置中保留"重新引导"入口

## 三、每日目标系统（P0）

### 问题
现在有进度条，但没有"目标"概念。用户不知道今天学多少才算够。

### 解决方案

#### 3.1 目标设置
欢迎页每日卡片下方增加目标区域：
```
今日目标：50 词  [编辑]
━━━━━━━━━━━━━━━━░░░░  23/50
```
- 默认值：50
- 用户可点击"编辑"修改（10/20/50/100/200/自定义）
- 目标存在 localStorage

#### 3.2 目标完成反馈
- 达成 50%：💪 "完成一半了！"
- 达成 100%：🎉 "今日目标达成！"
  - 展示庆祝动画（已有 confetti 效果可用）
  - 显示连续达成天数
- 目标超额完成（>100%）：🔥 "超额完成！"

#### 3.3 目标与进度条联动
- 欢迎页进度条直接按"今日已学 / 今日目标"计算百分比
- 不再按"标记词数/总词数"（这个移入网格页内部）

## 四、学习旅程（P1）

### 问题
现在词库之间是平级的，选了就学，没有"进展感"。用户学完四级不知道下一步该学六级。

### 解决方案：词库路径

#### 4.1 预设学习路径

| 路径 | 词库顺序 |
|------|---------|
| 🇨🇳 国内考试 | K12 → Gaokao → CET-4 → CET-6 |
| 🌍 出国留学 | Collins → IELTS → TOEFL → SAT → GRE |
| 💼 职场英语 | Collins → Business |
| 🎯 自由模式 | 任意选择，无路径 |

#### 4.2 词库完成状态
每个词库增加状态标记：
```
📚 CET-4        ✅ 已掌握 87%  [继续]
📚 CET-6        🔒 未解锁  [完成 CET-4 后解锁]
📚 IELTS        🔓 已解锁  [开始]
```
- 自由模式下所有词库都解锁
- 路径模式下，上一词库掌握率 > 80% 解锁下一个

#### 4.3 完成度统计
- 每个词库的掌握率：已掌握词数 / 总词数
- 从复习池中统计：status === 'mastered' / 总词数
- 总进度：当前路径所有词库的平均掌握率

## 五、成就/徽章系统（P1）

### 问题
现在的正向反馈只有 streak 计数和连续答对动效，太单薄。

### 解决方案

#### 5.1 徽章类型

| 类别 | 徽章 | 条件 |
|------|------|------|
| 🎯 学习 | 「初次学习」 | 完成第一个 Batch |
| 🎯 学习 | 「七日行」 | 连续学习 7 天 |
| 🎯 学习 | 「半月谈」 | 连续学习 15 天 |
| 🎯 学习 | 「满月」 | 连续学习 30 天 |
| 🎯 学习 | 「百日功」 | 连续学习 100 天 |
| 🧠 词汇 | 「百词斩」 | 累计掌握 100 词 |
| 🧠 词汇 | 「千词户」 | 累计掌握 1000 词 |
| 🧠 词汇 | 「词霸」 | 累计掌握 5000 词 |
| 🧠 词汇 | 「词库毕业」 | 完成一个词库（掌握率 > 80%） |
| 📚 词库 | 「四级通过」 | CET-4 掌握率 > 80% |
| 📚 词库 | 「六级通过」 | CET-6 掌握率 > 80% |
| 📚 词库 | 「GRE 通关」 | GRE 掌握率 > 80% |
| 🧪 测验 | 「全对」 | 一次测验 10/10 |
| 🧪 测验 | 「百分先生」 | 连续 3 次测验全对 |
| 🔄 复习 | 「第一次复习」 | 完成第一次 SM-2 复习 |
| 🔄 复习 | 「复习达人」 | 累计完成 100 次复习 |
| 🏆 特殊 | 「元学习」 | 使用阅读模式完成第一次学习 |
| 🏆 特殊 | 「数据自由」 | 配置 WebDAV 同步 |
| 🏆 特殊 | 「工具箱」 | 使用过全部学习模式 |

#### 5.2 UI 展示

**欢迎页新增「成就」区域：**
```
┌── 成就 ──────────────────────┐
│ 🏆 4/19 个徽章已解锁          │
│                              │
│ [✅初次学习] [✅七日行]        │
│ [🔒半月谈] [✅百词斩]         │
│ [🔒千词户] [🔒数据自由]      │
│                              │
│          [查看全部 →]          │
└──────────────────────────────┘
```

**徽章详情页：**
- 所有徽章折叠展示（已解锁在前，未解锁在后灰色展示条件）
- 点击徽章展示获取时间 + 描述

#### 5.3 实现
- 新建 `badges.js` — 徽章条件检测 + 持久化存储
- 每次完成 batch / 复习 / 测验 后自动检测解锁
- 解锁时有 toast 通知 + 微动效

## 六、每日挑战（P2）

### 问题
日常学习之外没有一个"小惊喜"。每天打开都是一样的流程，缺乏新鲜感。

### 解决方案

#### 6.1 每日一道题
- 每天出一道不同的题
- 来源：从未在复习池中出现过的词中随机选一个
- 题型：看词选义（4 选 1）

#### 6.2 UI 位置
- 欢迎页左下角独立卡片：🌅 每日挑战
- 答完后展示正确答案 + 释义
- 答对/答错都记录在 localStorage
- 连续答对 7 天获得隐藏徽章

#### 6.3 注意
- 不占学习进度
- 不强提醒（不弹窗）
- 每天 0 点刷新

## 七、核心流程极致优化（P1）

### 7.1 从欢迎页到第一个词 → 2 次点击
```
当前：
选择词库 → 点开始学习 → 骨架屏 → 看到词
（2 次点击 + 加载）

目标（点击"继续学习"时）：
→ 直接进入上次未完成的批次
→ 或直接从上次词库的下一批开始
→ 0 次选择，1 次点击
```

### 7.2 Batch 切换零等待
- 当前批次完成后，"下一批"按钮预加载下一批数据
- 用户点击"下一批"时，数据已在内存中，直接渲染

### 7.3 详情页预加载
- 进入网格页时，后台启动所有词的详情加载
- 用户标记完词、点"Next"时，详情已就绪，跳过 loading 状态
