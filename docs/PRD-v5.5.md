# VocabLearn v5.5 — 体验精简与深度打磨

> 日期：2026-05-17
> 阶段：体验评审 → 方案 → 实施

---

## 一、问题诊断

### 问题 1：屏幕太多了（核心问题）

当前 10 个屏幕 + 2 个模态框：

```
Welcome → Loading → Grid → Detail → Done
Review  Quiz  Dictation  Cloze  Reading
(2 modals: Settings, Source)
```

对于一个单词学习工具来说太多了。用户要在 5 种学习模式间来回切换：Learn / Review / Quiz / Listen / Cloze。认知负担不降反增。

**问题本质**：功能堆上去了，但没有收敛入口。

### 问题 2：词网格缺"窥探"交互

当前点击词块 = 标记为陌生。但用户很多时候只是想**看一眼**这个词的意思再决定。现在的交互强迫用户做出二元选择（认识/不认识），没有"让我看看"的中间态。

### 问题 3：测验/听写/完形与主流程隔离

完成一批学习后，用户要手动切到另一个模式才能测验。学习→测验应该是同一个流程里的自然衔接，而不是两个独立功能。

### 问题 4：进度不持久

用户如果学到一半关了浏览器，当前批次的标记状态就丢了。下次打开只能重新开始一批。

### 问题 5：Loading screen 是摩擦点

每次生成/加载词都要经过一个单独的 loading 屏幕，1-2 秒的等待被放大成了一整屏中断。

---

## 二、改进方案

### 2.1 屏幕收敛（P0）

重新规划底部导航为 4 项：

| 当前（6 项） | 改为（4 项） | 理由 |
|-------------|-------------|------|
| Learn | **Learn** | 主流程不变 |
| Review | **Review** | 不变 |
| Quiz / Listen / Cloze ⛔ | **Practice** 🔵 | 三个测验模式合并为一个入口，内部通过选项卡切换 |
| Settings | **Settings** | 不变 |
| — | 新增 **Reading** 放入 Practice | 阅读模式本质也是"学词"，归入 Practice |

**Reading 模式**从独立屏幕移入 Practice 下的第四个选项卡。

### 2.2 词网格窥探交互（P0）

**新增交互方式**：长按 / 双击 / 右键 词块 → 弹出浮窗显示释义 + 音标 + 例句。

**交互规则：**
- 单击词块 = 标记/取消标记（不变）
- 长按(500ms) 词块 = 弹出窥探浮窗
- 窥探浮窗：显示 chineseDef + pronunciation + definition，底部"标记陌生"和"标记熟悉"两个按钮
- 浮窗自动 3 秒后关闭，或点击外部关闭
- 窥探不改变词的标记状态

**实现方式：**
- 新增 `peekPopup` 元素（absolute 定位浮窗）
- `mousedown` + `setTimeout` 500ms 判断长按
- `touchstart` + `touchend` 判断移动端长按
- 浮窗动态定位在词块附近（防溢出屏幕）

### 2.3 嵌入"快速测验"到完成页（P1）

**现状**：完成一批后 → 看统计 → 手动切到 Quiz 模式 → 选词 → 开始测验

**改进**：完成页直接加一个"快速测验"区域
- 从当前批次随机抽 5 词（看词选义）
- 内嵌在 done screen 中，不需要切换屏幕
- 答完即出分，错词加入复习池
- 底部仍然保留"下一批"按钮

**UI 布局：**
```
┌─── Done Screen ───────────────────┐
│  ✓ Batch Complete!                 │
│  [Familiar: 87] [Unfamiliar: 13]   │
│                                     │
│  ─── 快速测验 ───                   │
│  从本批词汇中抽 5 题                │
│  "ephemeral" 的意思是？             │
│  [A] 永恒的 [B] 短暂的 [C] 坚固的   │
│  [D] 复杂的                         │
│                                     │
│  得分: 4/5  错词已加入复习池        │
│                                     │
│  [Next Batch →]  [Full Quiz →]      │
└─────────────────────────────────────┘
```

### 2.4 进度持久化（P1）

**问题**：mid-batch 关闭浏览器，标记状态丢失。

**解决方案：**
- 在 `storage.js` 中增加 `SessionSnapshot` 模块
- 每次用户标记/取消标记词块时，自动保存快照：
```js
{
  batchIndex: 3,
  currentWords: [/*当前批次所有词*/],
  markedIndices: [2, 7, 15, ...],
  sourceType: 'builtin',
  vocabId: 'cet4',
  timestamp: Date.now(),
}
```
- 欢迎页检测是否有未完成的批次快照
  - 有 → 顶部卡片显示"有未完成的批次，是否继续？" + 继续/放弃按钮
  - 无 → 正常展示
- 快照保留 24 小时，过期自动清除

### 2.5 消除 Loading 屏幕（P2）

**问题**：每次开始学习都经过 loading → grid 两个屏幕切换。

**解决方案：**
- 点击"继续学习"或"选择词库"后：
  - 先展示词网格骨架屏（10 个灰色词块）
  - 异步加载词数据
  - 数据加载完成后骨架渐变为真实词块
  - 不再经过 screenLoading

**实现方式：**
- `startSession()` 直接调 `showScreen('grid')` + 骨架屏状态
- 加载完成后调用 `renderWordGrid()` 替换骨架
- 如果加载失败，展示错误提示 + 重试按钮（不返回到 welcome）

### 2.6 键盘快捷键覆盖全屏（P2）

| 屏幕 | 快捷键 |
|------|--------|
| Grid | `M` 标记当前选中词 | `F` 搜索 | `/` 聚焦搜索框 |
| Detail | `Enter` 确认 | `←` 返回网格 | `→` 下一个词 |
| Review | `1/2/3/4` Again/Hard/Good/Easy | `Space` 发音 |
| Done | `D` 下载记录 | `A` 导出 Anki | `Space` 下一批 |
| Quiz/etc. | `1/2/3/4` 选 ABCD | `Enter` 提交 | `R` 重新开始 |
