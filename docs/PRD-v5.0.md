# VocabLearn v5.0 — 交互体验与视觉美化

> 日期：2026-05-17

---

## 一、设计原则

1. **减少认知负担** — 用户打开就知道下一步做什么，不需要思考
2. **减少操作步数** — 任何常用操作不超过 2 次点击
3. **增加正反馈** — 每一次交互都有即时、愉悦的反馈
4. **风格统一** — 所有屏幕、组件、动效遵循同一套设计语言

---

## 二、欢迎页重设计（P0）

### 现状
标题 + 三行介绍 + 两个按钮 + 一行提示。信息层级模糊，用户不知道该先点哪个。

### 目标
用户打开页面，3 秒内理解"这是什么"+"我能做什么"，1 次点击开始学习。

### 设计方案

#### 顶部：每日学习卡片
```
┌─────────────────────────────────────┐
│  📅 今日学习                           │
│  ━━━━━━━━━━━━━━░░░░░  67/100 词     │
│  连续学习：5 天 🔥  待复习：23 词     │
│  上次学习：昨天 15:30                  │
└─────────────────────────────────────┘
```
- 大号进度条，视觉上展示今日完成度
- 下方三个数据指标：连续天数、待复习数、上次学习时间
- 数据为空时展示引导语："开始你的第一次学习吧！"

#### 中部：快速开始区域
```
┌─ 继续学习 ──────┐  ┌─ 复习生词 ────┐
│  上次词库：CET-4    │  待复习：23 词    │
│  进度：Batch 3     │  下次复习：SM-2   │
└──────────────────┘  └────────────────┘
```
5 列布局（自适应）：
1. **继续学习** — 一键回到上次词库和批次（高亮主按钮）
2. **复习生词** — 显示待复习数，有红点 badge
3. **选择词库** — 打开词库面板
4. **AI 生成** — 调用 DeepSeek
5. **文件导入** — 加载 .txt

#### 底部：快捷入口
```
[ 学习日历 ]  [ 常错词榜 ]  [ 导出 Anki ]  [ 设置 ]
```
- 图标 + 文字
- 冷门操作收在这里，不干扰主流程

### 交互细节
- 每日卡片数据从 localStorage 历史记录中自动汇总
- 首次访问（所有数据为空）展示引导动画或走马灯提示
- 进度条动画：加载时从左到右渐变填充

## 三、Screen 切换动画（P0）

### 现状
所有屏幕切换是瞬间跳转，没有过渡。

### 设计方案
所有 screen 切换增加 fade + slide 组合动画：

| 切换 | 动画 | 时长 |
|------|------|------|
| welcome → loading | fade-out + fade-in | 300ms |
| loading → grid | content slide-up + fade-in | 400ms |
| grid → detail | slide-left | 350ms |
| detail → grid (back) | slide-right | 350ms |
| detail → done | card collapse + success fade-in | 500ms |
| done → grid (next batch) | slide-up | 300ms |
| any → welcome | fade-in | 250ms |

### CSS 实现
```css
.screen {
  transition: opacity 300ms ease, transform 350ms ease;
}
.screen.slide-left {
  transform: translateX(-30px);
  opacity: 0;
}
.screen.slide-right {
  transform: translateX(30px);
  opacity: 0;
}
.screen.slide-up {
  transform: translateY(30px);
  opacity: 0;
}
.screen.fade {
  opacity: 0;
}
```

在 `app.js` 的 `showScreen()` 中：
1. 旧 screen 加上过渡类 → 等待动画完成
2. 切换 active 状态
3. 新 screen 加进入动画类 → 触发重排 → 移除动画类

## 四、微交互动效（P1）

### 4.1 词块标记动效
- 点击词块 → 0.15s 微缩放（scale 0.95 → 1.0）
- 从未标记到标记：黄色边框从中间扩散开（box-shadow ripple）
- 从标记到取消：颜色淡出，恢复默认样式
- 批量标记（全选/取消）：所有词块依次触发错开 30ms delay

### 4.2 详情入场动画
- 多张详情卡按 stagger 方式入场：每张卡间隔 80ms，从下方 slide-up + fade-in
- 单词文字本身从大号缩回（scale 1.2 → 1.0），突出"这个词是关键"

### 4.3 完成页庆祝
- 完成批次时：统计数字逐位滚动（从 0 变到实际值）
- 100% 熟悉率：特殊彩蛋动画（满屏星星飘落）
- 按钮 hover 状态增加微光效

### 4.4 复习页交互
- "记住了"/"没记住"按钮按压效果
- SM-2 四级自评（Again/Hard/Good/Easy）按钮颜色区分：
  - Again: 红色 (#f56565)
  - Hard: 橙色 (#ed8936)
  - Good: 蓝色 (#5b6ef5)
  - Easy: 绿色 (#3ecf8e)
- 连续答对 streak 显示增长动画

## 五、配色与主题（P1）

### 5.1 深色主题精细化
当前深色主题已经不错，但饱和度偏低。微调方向：

| 当前色值 | 新色值 | 用途 |
|---------|--------|------|
| #0f1117 | #0d1117 | 背景（更纯的黑） |
| #1a1d27 | #161b22 | 表面对（GitHub 风格） |
| #5b6ef5 | #5865f2 | 主色（Discord 蓝的稳定感） |
| #f0c040 | #f0c040 | 强调色（保留） |

### 5.2 浅色主题（新增）
- 背景：白色 #ffffff
- 表面：浅灰 #f6f8fa
- 文字：深灰 #24292f
- 主色保持 #5865f2
- 在设置面板增加"深色/浅色/跟随系统"三选一

### 5.3 主题切换实现
- 使用 CSS 自定义属性前缀 `--color-*`
- 添加 `[data-theme="light"]` 选择器覆盖颜色变量
- 检测 `prefers-color-scheme` 媒体查询
- 切换动效：100ms fade

## 六、组件视觉升级（P2）

### 6.1 按钮系统规范化
| 类型 | 用途 | 样式 |
|------|------|------|
| Primary | 主要操作 | 蓝色填充 + 白色文字 |
| Secondary | 次要操作 | 灰色边框 + 浅灰背景 |
| Ghost | 轻量操作 | 无边框，hover 才显现 |
| Danger | 危险操作 | 红色填充 |
| Large | 欢迎页主按钮 | 大号 + 微光晕 |

### 6.2 卡片体系
- 详情卡、复习卡、设置面板统一 border-radius 和 padding
- hover 时轻微上浮（translateY -2px）+ 阴影加深
- 选中/激活状态加左边框指示条（accent color）

### 6.3 空状态设计
所有可能为空的区域展示友好提示：

| 状态 | 展示 |
|------|------|
| 复习池为空 | 📭 "还没有待复习的词，先去学习吧！" + 按钮"去学习" |
| 今日未学习 | "今天还没开始学习，现在开始？" |
| 历史记录为空 | "你的学习记录会在这里展示" |
| 听写/完形池为空 | "选择一批词汇后再来挑战" |
| 同步未配置 | "配置 WebDAV 即可跨设备同步数据" |

### 6.4 品牌元素
- **Favicon**：使用 Vue / Vite 风格的书本 SVG 图标
- **Logo**：现有的 `VocabLearn` 文字渐变 logo 已经不错，PWA 启动屏/header 中保持一致
- **404/错误状态**：全局错误捕获兜底展示（目前 API 错误已有 toast，还需要兜底页面级错误）

### 7.1 骨架屏升级
当前已有的骨架屏（detail-card.skeleton）扩展到所有延迟加载区域：

| 区域 | 骨架样式 |

| 热力图 | 灰色点阵，加载完成后逐个填充颜色 |

### 7.2 过渡加载
