## 二、词网格交互重构（P0）

### 2.1 问题诊断

当前：
```
单击词块 → 标记为陌生（黄色边框）
长按 500ms → 弹出窥探浮窗（看释义）
```

用户来这个页面的目的：**判断这个词我认不认识。** 但他需要先选一个"工具"（单击还是长按）才能完成这个判断。这个"选工具"本身是多余的脑力消耗。

### 2.2 方案：单击 = 看，看了再决定

**新交互：**
```
单击词块 → 弹出释义浮窗（音标 + 中文释义 + 英文释义 + 例句）
              ↓
        浮窗底部两个按钮：
        [✓ 认识] [✗ 不认识]
              ↓
        选择后浮窗关闭，词块标记状态更新
```

### 2.3 好处

- **一次点击看到释义**，不是标记。用户先获取信息，再做选择。
- 把"标记"这个动作从"点击"解耦到"点击后选择"，降低了每次点击的心理门槛。
- 长按交互保留作为快速操作（可直接标记不认识，跳过浮窗）。

### 2.4 交互细节

| 操作 | 结果 |
|------|------|
| 单击词块 | 弹出释义浮窗（浮窗包含词的全部详情） |
| 浮窗中点击 ✓ 认识 | 词块变绿色（已掌握态），浮窗关闭 |
| 浮窗中点击 ✗ 不认识 | 词块变黄色（陌生态），加入复习池，浮窗关闭 |
| 浮窗外点击 | 浮窗关闭，词块状态不变 |
| 长按词块（>400ms） | **快速标记陌生人**：直接标记黄色，加入复习池，不弹浮窗 |

### 2.5 视觉设计

```
┌──────────────────────────────┐
│  ephemeral     /ɪˈfemərəl/ 🔊 │
│  adj. 短暂的，转瞬即逝的        │
│  lasting for a very short time │
│                              │
│  "the ephemeral beauty of     │
│   cherry blossoms"            │
│                              │
│   [✓ 认识]    [✗ 不认识]      │
└──────────────────────────────┘
```

浮窗样式：
- 暗色主题：深色毛玻璃背景（backdrop-filter: blur(16px)）
- 浅色主题：白色毛玻璃
- 居中或锚定在点击的词块附近
- 三角形 tail 指向点击的词块

### 2.6 可配置

设置面板增加"单击行为"选项：
- "单击查看释义"（新默认值）
- "单击直接标记"（老用户习惯）

## 三、词网格展示优化（P1）

### 3.1 搜索/筛选

词网格顶部增加搜索框：
```
┌──────────────────────────────────┐
│ 🔍 在词库中搜索...        [批量] │
└──────────────────────────────────┘
```
- 输入实时过滤词块（键盘输入每 300ms 更新一次）
- 支持中英文搜索（搜索 word 或 chineseDef）
- "批量"按钮展开批量操作：全选/取消全选/批量标记/批量取消

### 3.2 排序/分组

搜索框右侧下拉菜单：
- 随机排列（默认）
- 字母 A-Z
- 按难度（复习池中的 ef 值，ef 越低越难排前面）

### 3.3 分页（可选）

大屏展示 100 词没问题，小屏（<600px）可加选项：
- 每页 20 词
- 底部页码 / 滚动加载

## 四、详情页优化（P1）

### 4.1 交互优化

当前：
```
点击 Next → 展示所有陌生词的详情卡片 → 逐张滚动查看 → Confirm
```

改进：
- 详情页支持**左右滑动切换卡片**（已实现），加指示器显示 "3/13"
- 每张卡片增加"这不是陌生词"按钮，可取消标记
- **一键发音**：进入详情页自动朗读当前词（设置中可关）

### 4.2 信息密度

当前卡片：word + pronunciation + pos + definition + example + chineseDef
- chineseDef 已经加上了，很好
- 增加常用搭配（collocation），从词库或 API 获取（如果数据缺失则不展示）
- 例句增加中英文对照：

```
"the ephemeral beauty of cherry blossoms"
樱花的转瞬即逝之美
```

## 五、SM-2 算法增强（P2）

### 5.1 当前状态

核心实现干净无 bug，四个自评等级、EF 调整、旧数据迁移都做全了。

**可以增强的方向：**

### 5.2 分散复习（adaptive scheduling）

当前：今天到期的所有词一次性复习。
问题：同一天复习大量词会导致临时记忆（short-term memory boost），不是真实掌握。

改进：将当天到期的词按批次分散到不同的复习时段。
- 如果当天有超过 20 词待复习，拆成多个小批次
- 用户完成一批后，建议"休息一下，2 小时后再来"
- 如果用户一次性复习完，不做强制（但记录复习时间间隔）

### 5.3 遗忘曲线可视化

复习页增加"记忆健康"图：
- 横轴：时间
- 纵轴：预计记忆保持率（基于 SM-2 的 EF + interval 估算）
- 公式：保持率 ≈ e^(-interval / (EF * 2))
- 展示每个词当前记忆强度（高/中/低/遗忘）

### 5.4 质量自评优化

当前四档：Again(0) / Hard(2) / Good(4) / Easy(5)

可微调标签和颜色：
| 按钮 | 颜色 | 说明 |
|------|------|------|
| 完全忘了 | 🔴 #f56565 | quality=0，重置 |
| 有点印象 | 🟠 #ed8936 | quality=2，下次减半 |
| 记住了 | 🔵 #5b6ef5 | quality=4，正常推进 |
| 太简单了 | 🟢 #3ecf8e | quality=5，加速推进 |

### 5.5 复习回顾

每次完成复习后，展示一个简短回顾：
- 本次复习：N 词
- 答对率：X%
- 答错的词列表（可点开重新复习）
- 下次复习：明天有 X 词到期

## 六、批处理增强（P1）

### 6.1 批次预览

当前：用户不知道"我将要看哪些词"就开始了。

改进：开始前展示批次预览：
```
Batch 5 — CET-4
┌──────────────────────┐
│ 正在学习 100 个新词    │
│                      │
│ 第一批你今天将看到：   │
│ ephemeral, ubiquitous, │
│ loquacious, ... +97   │
│                      │
│ 预计用时：5-10 分钟    │
│                      │
│     [开始]  [取消]     │
└──────────────────────┘
```

### 6.2 批次进度增强

当前：顶部的进度条只显示"标记数/总词数"。

改进：增加"批次用时"计时器 + "平均用时/词"统计：
```
Batch 3         ⏱ 2:30  1.5s/词
━━━━━━━━━━━━━━━░░░  67/100
```

### 6.3 智能批次大小

当前：用户设置每批 N 词，始终固定。

改进：可选"自适应批次大小"：
- 根据用户历史完成率自动调整
- 如果用户经常标记 > 50% 为陌生 → 减少每批词数
- 如果用户经常标记 < 10% 为陌生 → 增加每批词数
- 用户在设置中开关
