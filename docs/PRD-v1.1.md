> 版本：v1.1（规划中）
> 日期：2026-05-17
> 状态：草案

---

## 一、产品概述

### 1.1 定位
一款轻量级、纯前端的英语单词学习工具。打开即用，零依赖，零部署。

### 1.2 目标用户
- 有英语背词需求的成年人（学生、职场人士）
- 不想装 App、不想注册账号、打开浏览器就能学的用户
- 自己已有词库，只想找个干净的工具来辅助学习的用户

### 1.3 用户故事

| 角色 | 故事 |
|------|------|
| 上班族 | "我每天通勤想刷 50 个词，不想再打开一个臃肿的 App" |
| 学生 | "我有一份 GRE 生词表，想导入进去反复记" |
| 自学者 | "我不想花钱买词库，AI 能根据我的水平自动生成" |
| 人人 | "标记为陌生的词，过两天能自动再出现让我复习" |

## 二、当前已实现功能（MVP v1.0）

### 2.1 核心学习流
1. **欢迎页** → 点击"开始学习" / "从文件加载"
2. **词汇生成/加载** → AI 生成 或 文件导入
3. **词网格** → 展示单词，点击标记陌生词
4. **详情回顾** → 展示陌生词的音标、词性、释义、例句
5. **完成页** → 统计本轮熟悉/陌生词数，下载记录

### 2.2 双词源

**来源 A：AI 生成**
- 调用 DeepSeek API（兼容 OpenAI 协议）
- 支持 5 个难度等级：初级(A1-A2) / 中级(B1-B2) / 高级(C1-C2) / 学术/GRE / 商务
- 自动排除当日已用词

**来源 B：文件导入**
- 支持 .txt 文件（一行一词 / 逗号分隔 / 空格分隔）
- 自动去重
- 批量导入多个文件

### 2.3 会话管理
- 按天隔离——跨天自动重置
- 去重——当天已学词不再出现
- 批次递增——Batch 1 → 2 → 3...
- 熟悉/陌生词按日累积统计

### 2.4 记录系统
- 每完成一批自动下载 Markdown 记录文件
- 同步保存到 localStorage
- 记录含：词数统计、熟悉词列表、陌生词列表

### 2.5 设置项
| 设置 | 默认值 | 范围 |
|------|--------|------|
| DeepSeek API Key | 空 | — |
| 每批词数 | 100 | 10-500 |
| 难度等级 | 中级(B1-B2) | 5 档 |
| 词源 | AI | AI / 文件 |

### 2.6 技术实现
- 纯 HTML + CSS + JS，零框架零依赖
- 数据持久化：localStorage
- 深色主题
- 响应式设计（桌面 + 移动端）
- 骨架屏加载动画
- 模态框设置面板

## 三、待开发需求（v1.1 规划）

### 3.1 复习机制（P0 — 最高优先级）

**背景：**
标记为"陌生"的词，查看详情后就被丢弃了。没有间隔重复（SRS），没有回头复习的入口。这是当前最大的功能缺口。

**需求描述：**

3.1.1 陌生词池
- 所有被标记为"陌生"的词自动归入"陌生词池"
- 词池按日、周、全部分层
- 提供"复习陌生词"入口（独立于主学习流）

3.1.2 间隔复习
- 简单 SRS 算法：第一天看完 → 第二天 recall → 第四天 recall → 第七天 recall → 标记为"已掌握"
- 每次 recall 正确则延长时间间隔，错误则缩短

3.1.3 复习态标记
- "陌生"→"复习中"→"已掌握"
- 已掌握的词不再出现在陌生词池

3.1.4 复习模式
- 独立流程：进入复习模式 → 展示词列表 → 点击标记"记住了/没记住" → 按 SRS 算法安排下次出现

**验收标准：**
- 用户标记为陌生的词，第二天打开页面时能看到复习提示
- 复习至少有 "看词回忆释义" 模式
- 复习通过后可标记为"已掌握"

### 3.2 测验模式（P1）

**背景：**
当前只有"看词→判断认识不认识"的被动识别。缺少主动 recall，长期记忆效果不足。

**需求描述：**

3.2.1 看词选义
- 展示一个单词，给出 4 个中文选项，选对继续

3.2.2 看义选词
- 展示一个中文释义，给出 4 个英文选项，选对继续

3.2.3 拼写测验
- 展示中文释义，用户输入英文拼写，自动判断对错
- 支持模糊匹配（标点符号容错）

3.2.4 测验数据
- 正确/错误次数统计
- 常错词自动加入陌生词池

**验收标准：**
- 三种模式可切换
- 每次测验 10 题，答完出分
- 错题自动归入陌生词池

### 3.3 单词发音（P1）

**需求描述：**
- 详情页每个词旁加喇叭图标
- 点击朗读单词发音
- 例句旁加喇叭图标，可朗读例句
- 使用 Web Speech API（SpeechSynthesis），零依赖

**验收标准：**
- 点击即发音，无延迟
- 支持英文标准发音
- 无网络时也能发音（SpeechSynthesis 离线可用）

### 3.4 进度可视化（P2）

**需求描述：**
- 在欢迎页或独立页面展示学习日历热力图（类似 GitHub 贡献图）
- 显示：今日已学词数、本周趋势、连续学习天数

**交付形式：**
- 用 Canvas 或简单 HTML 表格实现热力图
- 数据来源为 localStorage 中的历史记录

### 3.5 键盘快捷键（P2）

| 按键 | 操作 |
|------|------|
| Space | 开始学习 / 下一批 |
| M | 标记/取消标记当前悬停词 |
| Enter | 确认并继续 |
| Escape | 关闭模态框 / 返回上级 |
| ← / → | 上一批 / 下一批 |

### 3.6 API 缓存与离线支持（P2）

- AI 生成的词列表缓存到 localStorage
- 同一批次状态下可离线查看已生成的词
- 详情页数据缓存

### 3.7 记录下载优化（P3）

- 改为"仅在退出会话/切换日期时下载"
- 增加"手动下载"按钮
- 增加"查看历史记录"功能（加载 localStorage 中保存的历史数据）

## 五、技术架构建议

```
┌──────────────────────────────────┐
│          UI 层 (HTML+CSS)         │
│   Welcome / Grid / Detail / Done  │
├──────────────────────────────────┤
│         逻辑层 (app.js)           │
│   状态机 + 事件路由 + 屏幕切换    │
├──────────────────────────────────┤
│         API 层 (api.js)           │
│    DeepSeek 调用 / 词生成 / 详情  │
├──────────────────────────────────┤
│       存储层 (storage.js)         │
│    localStorage / 记录文件生成    │
├──────────────────────────────────┤
│        新增：复习引擎 (复习模块)   │
│    SRS 调度 / 测验生成 / 遗忘曲线 │
└──────────────────────────────────┘
```

**新增模块建议独立文件：**
- `review.js` — SRS 调度引擎 + 复习状态管理
- `quiz.js` — 三种测验模式的生成和评分
- `stats.js` — 统计数据收集 + 热力图渲染
- `tts.js` — 发音功能（基于 Web Speech API 封装）

### 7.2 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| DeepSeek API 需要外网 | AI 生成不可用 | 文件导入作为备选 + API 缓存 |
| localStorage 容量上限(5MB) | 历史数据过多时溢出 | 定期清理 + 提供导出功能 |
| 用户没有 API Key | 无法使用 AI 模式 | 引导文件导入，首页文案优化 |
| SRS 算法过于复杂 | 开发周期长 | 先上简化版（3 段间隔），后续优化 |
