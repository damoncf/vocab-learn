# VocabLearn v8.0 — 移动端深度优化

> 日期：2026-05-24

---

## 诊断数据

### 欢迎页
- 滚动高度 1191px（视口只 844px），首屏装不下
- 四个底部快捷按钮（`.qa-btn`）全部小于 44px 触摸目标
- 每日统计三块（`.daily-stat`）全部小于 44px
- 信息层级太多：每日卡片 + 2×3 网格 + 快捷入口 + 热力图 + 每日挑战

### 词网格
- 100 个词 × 48px 高度 × 3 列 = 33 行 ≈ 1600px 滚动
- 手机上默认 100 词过于激进

### 核心问题
**不是修修补补的问题，是桌面设计直接压到手机上。** 手机上需要另一种布局。

---

## 方案

### 1. 欢迎页移动端专用布局

**桌面端不动**，移动端（≤600px）使用简化布局：

```
┌─────────────────────────────┐
│ 📅 今日   🔥 5天  📚 12词  │ ← 更紧凑的信息行
│ ━━━━━━━━━━━━━━━━░░  23/50  │ ← 进度条
│                             │
│  ┌──────┐ ┌──────┐         │
│  │ 继续  │ │ 复习  │         │ ← 2×2 网格（更少、更大）
│  ├──────┤ ├──────┤         │
│  │ 词库  │ │ 更多  │         │
│  └──────┘ └──────┘         │
│                             │
│  🌅 每日挑战                 │ ← 轻量卡片
│  ephemeral 的意思是？        │
│  [A] 短暂的 [B] 永恒的       │
│                             │
└─────────────────────────────┘
```

**具体改动：**
- 每日卡片：数据行合并为一行，去掉大图标，缩小 padding
- 2×3 网格 → 2×2 网格（只保留最常用的 4 个：继续学习、复习、词库、更多）
- 底部快捷入口（`.qa-btn`）移到"更多"里面
- 热力图在移动端默认收起，可展开
- 每日挑战卡片嵌入欢迎页，不占额外空间

### 2. 触摸目标全部 ≥ 44px

| 组件 | 当前 | 目标 |
|------|------|------|
| `.qa-btn` | 约 30×30px | 48×48px |
| `.daily-stat` | 约 100×40px | 调整为非交互元素，或加大到 48px |
| `.word-chip` | 48px 高（已达标）| 保持 |
| `.mobile-nav-btn` | 44px（已达标）| 保持 |
| `.btn` (某些幽灵按钮) | 20px 高 | 36px 最小 |

### 3. 词网格移动端分批

移动端默认批次大小改为 20 词（而非 100）：
- 欢迎页卡片上加 "每批 N 词" 显示
- 设置中"每批词数"建议值加提示
- 20 词 × 3 列 = 7 行，一屏可看完

### 4. 页面滚动优化

- 欢迎页整体 padding 减少（desktop 保持）
- 每日卡片 padding: var(--space-5) → var(--space-3)（移动端）
- 2×2 网格卡片 padding 减少，间距缩小
- 移除不必要的底部留白

### 5. 测验/听写/完形/阅读 移动端适配

检查所有独立屏幕的移动端样式是否到位：
- 测验选项按钮：44px 最小高度
- 听写输入框：占满宽度，大字号
- 完形选项：横向两列改为纵向堆叠
- 阅读文章区：字体增大，间距加宽
